## 📖 项目简介
本项目是继 YOLO 项目之后的第二个项目，旨在跨越机器人仿真与 ROS2 全栈开发。

通过本项目，将搭建一套符合工业级标准的四足机器人（仿生狗）仿真系统。项目内容包括使用 URDF/Xacro 进行机器人运动学与几何模型的精细化建模，并在 Gazebo 物理引擎中实现本体、关节动力学以及 IMU、激光雷达（LiDAR）、RGB 相机等关键传感器的仿真配置。同时深入理解基于 ROS2 Topic / Service 的节点通信机制，实现机器人实时状态与传感器数据的采集，并结合 RViz2 完成三维数据流的可视化。

本仿真平台旨在降低算法测试的硬件成本与损坏风险，为后续的运动控制（步态规划）、视觉感知、SLAM 实时建图与自主导航等高级算法验证提供工程基础设施。

## ⚙️ 核心技术栈
- **系统环境**：Linux (Ubuntu)、容器化 (Docker)
- **机器人中间件**：ROS2 (Galactic/Humble)
- **仿真与建模**：Gazebo 物理仿真、URDF/Xacro 机器人建模
- **可视化与通信**：RViz2 数据可视化、LCM / ROS2 Topic 通信机制

## ✨ 核心任务与功能
- **环境搭建**：在本地电脑成功配置 Ubuntu 环境（虚拟机/双系统/WSL2）及 Docker。
- **仿真环境构建**：成功搭建 CyberDog 仿真环境。
- **三维可视化**：成功运行 Gazebo + RViz2 仿真程序。
- **传感器挂载**：在机器狗模型上挂载相机和激光雷达。
- **运动控制**：启动运动控制管理程序，在仿真环境中使机器狗正常运动。
