# 新图片验证结果（Level 4）

## 输入

`scene_input.jpg`（1224×576），一张训练集之外的新图：
左边蓝色方块、中间红标可口可乐瓶、右边足球。

## 模型与参数

- 权重：`weights/best.pt`（robot_dataset，yolo11n，50 epochs）
- imgsz：640
- conf：0.25（默认）

## 检测结果

| 目标 | 结果 | 置信度 | 框 (x1, y1, x2, y2) |
|---|---|---|---|
| football（足球） | ✅ 检出 | 0.78 | 902.3, 159.1, 1114.6, 366.3 |
| obstacle（蓝方块） | ✅ 检出 | 0.45 | 23.9, 147.3, 274.0, 391.5 |
| cola（可乐瓶） | ❌ 漏检 | — | — |

**3 个目标检出 2 个。**

结果图：`result_640.jpg`（带框、类别、置信度）。

## 为什么 cola 没检出？

- 训练集里的 cola 基本都是**深色瓶身**的可乐瓶，场景是机器人比赛场地；
- 这张测试图是**透明瓶身 + 红色标签**的可口可乐塑料瓶，灰色地毯背景；
- 两者外观、颜色、上下文差异很大，属于训练分布外（domain gap）。
- 紧裁测试里模型只对瓶身下半段的深色液体产生 0.56 响应，说明它主要抓的是“深色瓶子”特征，
  红色标签、透明瓶身这些新特征没有学到。

验证集上的 cola 召回率是 0.98，说明模型对训练里那种深色瓶子识别很好；
这次漏检不是阈值问题，而是**没见过这种外观**。

为了确认不是图本身不清楚，用 COCO 预训练的 `yolo11n.pt` 在同一张图上测试：
能检出 `bottle 0.87` 和 `sports ball 0.79`，说明瓶子和足球本身是清晰可辨的。

## 尝试过但没有采用的方案

| 尝试 | 结果 |
|---|---|
| conf 降到 0.05 | 仍然没有 cola |
| imgsz 960 | 把足球误判成 cola（0.65），不可靠 |
| imgsz 1280 | 出现多个错误 cola 框，不可靠 |
| 紧裁瓶子区域 | 对瓶身下半段（深色液体）有 0.56 的 cola 响应，但框不完整，只覆盖下半段 |

所以最终采用 imgsz=640、conf=0.25 的干净结果：检出了 obstacle 和 football，cola 漏检。

## 建议

1. 如果只是作业/报告：这张图可以作为“泛化能力不足/失败案例”的分析素材，
   说明训练数据外观覆盖不够，模型对新样式可乐瓶泛化差。
2. 如果希望 cola 也能检出：补 30~50 张这种红标可乐瓶（不同角度、不同背景）标好，
   加入 `robot_dataset` 重新训练/微调。
3. 注意：一旦把这张图加入训练，它就不能再当“新图片验证”用了。
