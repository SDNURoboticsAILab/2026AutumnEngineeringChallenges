\# 工程挑战赛项目报告 - 20261160331



\## 1. 项目简介

本项目基于 \*\*YOLOv8n\*\* 深度学习模型，成功构建了一个能够精准识别 \*\*Cola（可乐）、Football（足球）、Obstacle（障碍物）\*\* 三类目标的视觉检测系统。项目涵盖了从数据预处理、模型训练、性能评估到推理预测的完整全流程。



\## 2. 环境配置与依赖

本次实验在 Windows 系统下进行，核心框架与参数如下：

\- \*\*模型架构\*\*: YOLOv8n (Nano, 轻量级高性能)

\- \*\*Python 版本\*\*: 3.10+

\- \*\*深度学习框架\*\*: PyTorch, Ultralytics

\- \*\*依赖安装\*\*: 详见项目根目录下的 `requirements.txt` 文件。



\## 3. 数据准备与标注

\- \*\*数据集结构\*\*: 数据集位于 `dataset/` 文件夹下，严格划分为 `train`（训练集）和 `val`（验证集）子目录。

\- \*\*标注类别\*\*: `data.yaml` 配置文件定义了 `nc: 3`，对应类别为 `\['cola', 'football', 'obstacle']`。

\- \*\*标注格式\*\*: 采用标准的 YOLO 格式（.txt 标注文件）。



\## 4. 模型训练与评估

\### 4.1 训练参数

为了达到最佳的检测效果，模型训练配置如下：

\- \*\*Epochs\*\*: 100

\- \*\*Image Size\*\*: 640x640

\- \*\*Batch Size\*\*: 16



\### 4.2 性能指标

经过 100 轮的训练，模型在验证集上表现出了极高的精度：

\- \*\*mAP@0.5\*\*: 最终达到了 \*\*0.992\*\* (即 99.2%)。

\- \*\*精确率(Precision)与召回率(Recall)\*\*: 均保持在 0.9 以上的高水平。

\- \*\*Loss 曲线\*\*: 随着训练轮数的增加，训练损失与验证损失均呈现稳步下降趋势，收敛效果良好。

\## 6. 遇到的问题与解决方案

\- \*\*问题1\*\*: 初次配置环境时，部分 Python 依赖库版本不兼容导致报错。

&#x20; - \*\*解决方案\*\*: 通过创建独立的 Python 虚拟环境 `(myenv)`，并利用 `requirements.txt` 统一安装固定版本的依赖，成功解决了版本冲突问题。

\- \*\*问题2\*\*: 训练过程中，路径错误导致 `data.yaml` 无法找到图片。

&#x20; - \*\*解决方案\*\*: 将路径修改为基于项目根目录的相对路径，确保代码在任何环境下都能顺利运行。

\-\*\*问题3\*\*：在训练模型的过程中，乱改物体类别顺序，导致最后的类别与实物不匹配

&#x20; -\*\*解决方案\*\*：寻找旧版本的ymal文件，从中取回了正确的顺序

\## 7. 项目总结

本项目成功实现了基于 YOLOv8n 的高精度多目标检测。通过合理的参数调整和数据管理，模型在极短的训练周期内便达到了极高的准确率。这不仅验证了 YOLOv8n 模型的强大性能，也为未来在实时检测场景下的进一步落地应用打下了坚实基础。
