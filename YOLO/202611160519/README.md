# 明子翔的YOLO项目
基于 Ultralytics YOLO 的机器人场景目标检测，识别 obstacle、cola、football 三类目标。
完整实现了数据集整理、目标标注、模型训练、新图片推理的工程流程，并提供可视化界面（训练 / 自动标注 / GT 库管理 / 数据增强 / 开卷学习 / 错题本）。

## 四、数据准备
### 1. 目录结构

把原始图片放入：
dataset/images/train/     训练集图片
dataset/images/val/       验证集图片
**注：验证集请放入图片，无论是不是验证用的。**

对应的 YOLO 标签放入：
dataset/labels/train/     训练集标签（和图片同名 .txt，用自动标注功能的话无需进行二次操作）
dataset/labels/val/       验证集标签

### 2. 类别编号
0 = obstacle（障碍物）
1 = cola（可乐）
2 = football（足球）

### 3. 标签格式
每张图对应一个 .txt，每行一个目标：
类别编号 中心x 中心y 宽 高
坐标全部归一化到 0~1。示例：

1 0.512 0.634 0.231 0.418
0 0.334 0.521 0.120 0.300

注：如果嫌麻烦可以用自动标注页面的工具并进行手动修正（毕竟完备的模型没有训练出来）

## 五、使用教程
### 启动
**推荐用 CMD / PowerShell 启动，不要用 IDLE（IDLE 会拖慢训练）**
启动后主界面有 6 个标签页：

[训练] [自动标注] [GT 库管理] [数据增强] [开卷学习] [错题本]

### 标签页 1：训练
用途：用数据集训练 YOLO 模型。

参数说明：
| 参数 | 含义 | 推荐值 |
|---|---|---|
| data.yaml | 数据集配置文件路径 | 自动填充 |
| 基础权重 | 预训练权重 | yolo11n.pt |
| 继续训练 | 加载已有 best.pt 继续训练 | 可选 |
| epochs | 训练轮数 | 50~100 |
| imgsz | 输入尺寸 | 416（CPU）/ 640（GPU） |
| batch | 批大小 | 8（CPU）/ 16（GPU） |
| device | 训练设备 | cpu 或 0 |
| 版本名 | 输出目录名 | 自定义 |

操作步骤：
1. 确认 data.yaml 路径正确
2. 点「数据集统计」查看数据健康度与相关建议，当然只是建议。
3. 设置 epochs / imgsz / batch
4. 点「开始训练」
5. 观察进度条、loss、mAP50 实时更新
6. 训练完成后，权重保存在 runs/train/<版本名>/weights/best.pt

训练曲线：训练结束后，runs/train/<版本名>/results.png 包含所有指标曲线。

**（如果报错的话八成是你的yaml文件里的路径错了）**
**在下载文件后一定一定要检查路径！**
**注：由于文件上传缓存区限制，已经把dataset中的文件删除了，如果想再次开始训练，请务必保证via中有3个文件、train中有文件，这很简单，把图片放进train里，用自动标注页给标注好，然后人工手动审核调整即可**

### 标签页 2：自动标注
用途：用现有模型对新图片批量自动标注，然后人工审核。

操作步骤：
1. 确认「图片目录」= dataset/images/train
2. 确认「待审核标签目录」= dataset/labels_pending
3. 确认「正式标签目录」= dataset/labels/train
4. 设置「置信度」（默认 0.25，越低检出越多）
5. 点「开始自动标注」
6. 自动标注完成后，点「待审核列表」逐张审核

人工审核：
- 双击列表任意行 → 加载到审核画布
- 补标模式：勾选后拖拽画框
- 改类别：先点选一个框，下拉选类别，点「改类别」
- 删框：选中框，点「删框」
- 上一个 / 下一个：切换待审核图
- 通过：保存到 labels/train，自动切下一张
- 拒绝：进错题本
- 另存为训练数据：保存并切下一张
- 存为标准答案：加入 GT 库，后续用于模型的开卷学习（标记已审核）

批量操作（在待审核列表窗口）：
- Ctrl+A 全选 / Shift+点击连选
- 「批量加载」：把选中的图加载为审核队列
- 「批量删除」：删除选中的待审核文件

### 标签页 3：GT 库管理
用途：管理标准答案库（Ground Truth），审核标注质量。

为什么需要 GT 库：模型训练前，先保证"答案是对的"，否则学出来也是错的。

操作步骤：
1. 点「上传图片」选择一张图
2. 点「运行检测」自动检测
3. 手动修正框（补标模式 / 删除 / 改类别）
4. 点「存入 GT 库」（标记为待审核）
5. 在右侧列表双击该图 → 进入审核模式
6. 检查框和类别无误后，点「审核通过」

审核状态：
- ✓ 已审核：参与开卷学习
- ⚠ 待审核：需要人工确认

去重：点「去重」自动删除重叠度高的重复框。
Grubcut：一种自动匹配工具，拖拽框后自动匹配，类似PS中的魔棒
SAM：可以选择下载，其实就是一个加强版的Grubcut
设为必要框：必要框就是指模型必须认出的东西，如果认不出这个框就F1=0
合并：模型抽风在一个区域里标了多个相同标签可以用这个合并，减少框的数量

**注：GT库管理也是用于模型测试的部分，选择模型后该模型会用于后续的开卷学习部分，请注意**

### 标签页 4：数据增强
用途：对训练集做增强（亮度/对比度/饱和度/翻转/噪声/模糊/裁剪），扩充数据量。

操作步骤：
1. 确认图片目录 = dataset/images/train
2. 确认标签目录 = dataset/labels/train
3. 设置「增强倍数」（推荐 5，即每张原图生成 5 张）
4. 勾选「先清空旧的 aug_」
5. 点「开始增强」

增强后，dataset/images/train 和 labels/train 里会出现大量 aug_ 开头的文件。

**注：增强比例建议 3~5x。太低模型学不够，太高会过拟合**

### 标签页 5：开卷学习
用途：模型自我迭代——用已审核的 GT 反复训练、考试、对比，直到全部学会。

流程：
```
① 看答案     展示所有已审核 GT
② 摸底考试   记录模型当前水平（学习前 F1）
③ 开卷学习   用 GT 微调模型
④ 对比考试   对比学习前后，看是否真的变好
```

操作步骤：
1. 设置「IoU 阈值」
2. 设置「合格线 F1」
3. 设置「最大迭代」
4. 设置「每轮 epoch」
5. 设置「超时(分钟)」
6. 点「只考试一次」：仅评估，不训练
7. 点「开卷学习闭环」：完整迭代学习
8. 学习完成后，点「学习报告」查看学习前后对比，不满意就人工引导大力出奇迹。
9.满意模型后进行保存操作。
epoch就是指每轮模型学几次。

学习报告：
- 表格显示每张 GT 的学习前 F1 / 学习后 F1 / 变化
- 双击某行 → 弹出对比窗口（左=模型预测，右=GT）
- 顶部切换「学习前 vs 学习后」或「模型预测 vs 标准答案」

对比窗口：
- 绿框 = GT 命中
- 红框 = GT 漏检
- 蓝框 = 预测命中
- 粉框 = 预测误检
- 点「去修改 GT」跳转到 GT 库管理页修改标准答案

#### 模型杂交
点击模型杂交后选择要杂交的模型，然后点击开始融合后等待即可

### 标签页 6：错题本
用途：管理模型答错的图，支持批量操作。

操作：
- 双击条目 → 跳转到 GT 库管理页重审
- 批量操作（多选）：
  - 全选 / 反选
  - 批量重审
  - 批量移除
  - 批量加入训练集

## 七、常见问题
1. No labels found 报错
原因：dataset/labels/train 或 val 为空。
解决：确保每张图片都有对应同名 .txt 标签。

2. images not found 报错
原因：data.yaml 里的 path 路径错误。
解决：改成绝对路径，用正斜杠 /：

path: D:/你的路径/dataset
train: images/train
val: images/val

3. 训练速度很慢
原因：在 IDLE 里运行（GUI 渲染拖慢）；图片分辨率太大；数据量太多。
解决：改用 CMD / PowerShell 启动；缩小图片到 640 长边；减少 epochs。

4. 微调后识别能力反而下降
原因：灾难性遗忘（学习率太高，模型忘了旧知识）。
解决：用 lr0=0.001（本项目默认）；训练集至少 20 张；微调后立即用新图片验证。

5. 中文在图片上显示为方框
原因：PIL 默认字体不支持中文。
解决：本项目已自动尝试 msyh.ttc（微软雅黑）、simhei.ttf（黑体）等中文字体，Windows 系统默认可用。
