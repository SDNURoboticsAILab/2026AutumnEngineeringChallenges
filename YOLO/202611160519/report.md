# 明子翔的YOLO项目报告

## 一、项目简介

本项目基于 Ultralytics YOLO 实现对机器人场景中三类目标（obstacle、cola、football）的检测，完整实现了数据集整理、目标标注、模型训练、新图片推理的工程流程。

**项目独有优势**：本项目不局限于"训练一个 YOLO 模型"这一基础目标，而是开发了一套完整的可视化工程工具链，涵盖训练、标注、审核、增强、迭代学习等全部环节，将整个目标检测流程封装为图形界面操作，大幅降低了使用门槛。

## 八、可视化界面
本项目最大的特色是**开发了一套完整的可视化 GUI 工具链**，覆盖目标检测项目的全生命周期。相比仅实现训练脚本的传统方案，本项目的 GUI 提供了以下独有能力：

### 8.1 六大功能模块

**训练页**
参数配置、进度实时显示、loss/mAP 曲线联动，可视化的训练进度条，查找模型避免刚训练完的模型不知道在哪里

**自动标注页**
用现有模型对新图片自动标注 + 人工审核，一定程度上方便了标注

**GT 库管理页**
标准答案库管理 + 审核 + 去重 + 对模型的检测 + 必要标记，一定程度上提高了模型开卷学习时的修正能力

**数据增强页**
一键生成 5 倍增强数据，包括模糊化处理、色差处理等，训练时极大地提高了模型的抗干扰能力

**开卷学习页**
模型自我迭代：看答案 → 考试 → 学习 → 对比。参考高中的考试化学习模式，提高了模型自我微调修正的能力。
并且有对比页面，将模型出的错可视化地呈现出来，方便调试者安排二次训练时的侧重方向。
模型杂交：将各个模型在识别各类模型能力取最强并进行融合，理论上可以一次得到准确率（F1值）为1.000的模型。

**错题本页**
错误样本管理，可以让模型从易错的地方调整回来，也方便了调试者的查看

### 8.2 核心创新
#### 创新一：带审核机制的标准答案库（GT 库）
**问题**：传统训练流程中，如果标注错误，模型学出来的也是错的，而且错误无法被发现。
**解决**：本项目设计了「GT 库 + 审核」机制：
- 所有标注结果先存入 GT 库，标记为"待审核"
- 管理员逐张审核，确认答案正确后才标记"已审核"
- **只有已审核的 GT 才能进入训练**，保证训练数据质量

#### 创新二：开卷学习闭环
**问题**：模型训练后，哪些地方学会了、哪些没学会，传统方案看不出来。
**解决**：本项目实现了「开卷学习」闭环：
① 看答案 展示所有已审核 GT
② 摸底考试 记录模型当前水平（学习前 F1）
③ 开卷学习 用标准答案微调模型
④ 对比考试 逐张对比学习前后，看是否真的变好
我在这一版本对学习机制进行了调整，可以让模型在明确错误类型条件下更聪明地调整，并引入了人工引导机制，方便模型具体知道怎么改。

**逐框诊断**：对每张图，给出精确诊断：
- ✅ 命中：预测框和 GT 匹配（类别 + IoU ≥ 0.5）
- ✗ 漏检：GT 有框但模型没检出
- ✗ 误检：模型报的框在 GT 里没有
- ⚠ 类别错：位置对但类别错
![开卷学习](results/screenshots/level5_review.png)
![学习报告](results/screenshots/level5_report.png)

#### 创新三：对比可视化
学习报告里双击任意图，弹出对比窗口：
- 左：模型预测框（蓝=命中，粉=误检）
- 右：标准答案框
- 底部：逐框诊断详情
- 顶部切换：学习前 vs 学习后
![对比可视化](results/screenshots/level5_compare.png)

#### 创新四：自动去重
标注时容易重复画框（一个目标标了 2~3 个框）。本项目实现了基于 IoU 的自动去重：
- 两两计算 IoU，超过阈值（0.75）视为重复
- 保留面积最大的，删除其余
- 支持手动去重和训练前自动去重

#### 创新五：错题本 + 批量操作
模型答错的图自动进入错题本，支持：
- 按错误次数降序排序
- 双击重审
- 批量重选 / 批量移除 / 批量加入训练集

### 8.3 技术亮点
| 亮点 | 说明 |
| **线程安全** | 所有耗时操作在后台线程运行，主界面不卡顿 |
| **实时进度** | 训练进度、微调剩余时间、超时控制 |
| **中文字体自适应** | 自动检测系统可用中文字体 |
| **规则校验层** | 检测结果基于 HSV 色彩 + 长宽比自动过滤误检 |

## 九、遇到的问题与解决
1. **data.yaml 路径错误**：`path` 必须写绝对路径且用正斜杠 `/`
2. **验证集为空**：YOLO 报 "No labels found"，需补齐标注
3. **预训练权重下载失败**：手动下载 yolo11n.pt 放在项目根目录
4. **训练速度慢**：在 IDLE 里运行会被 GUI 拖慢，改用 CMD / PowerShell
5. **模型越练越傻**：微调学习率过高，改用 lr0=0.001
6. **中文字体乱码**：PIL 默认字体不支持中文，需指定系统字体
7. **超时机制失效**：`trainer.stop_training` 在新版本无效，改用抛异常强制中断
8. **训练出的模型太多，训练好的模型丢了**：模型寻找、模型另存为、模型测试排序

## 十、总结

本项目在完成 Level 1~5 全部要求的基础上，进一步开发了**完整的可视化工具链**，将目标检测的全流程（数据准备 → 标注审核 → 训练 → 评估 → 迭代学习）封装为图形界面操作。

**项目核心优势**：
- **闭环迭代学习**：开卷学习 + 逐框诊断 + 对比可视化
- **降低使用门槛**：全程 GUI 操作，无需命令行

通过本项目，我理解了 YOLO 目标检测的工程流程，并实践了软件工程中的模块化设计、线程管理、异常处理等能力。
