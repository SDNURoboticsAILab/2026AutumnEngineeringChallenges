# 基于 YOLO 的机器人场景目标检测

## 一、环境配置

我用的是自己的笔记本（Windows，显卡 RTX 5060）。

装 Miniconda 时下载链接一直 404，换成官方源才下下来。装完用 conda 建环境，又报 SSL 证书错误，试了几次没通，改用 Python 自带的 venv 建了个独立环境。

跑通的版本：

- Python 3.14
- PyTorch 2.11.0（CUDA 12.8 版）
- ultralytics 8.4.173
- 显卡：NVIDIA GeForce RTX 5060 Laptop

装完跑了 `torch.cuda.is_available()`，返回 True。

## 二、数据整理

实验室给了三类图片：obstacle（障碍物）、cola（可乐）、football（足球），分别放在三个文件夹，是机器人视角拍的。

我没把全部标完，从每类挑了一部分当训练子集，一共标了 29 张：可乐 10、足球 10、障碍物 9（有一张漏标了）。

## 三、数据标注

标注最花时间。要求里对三个类别只给了名字，没更细的定义，我按"图从哪个文件夹来，就框图里对应的那个目标"来标。

一开始用在线标注网站，界面全英文，看不懂，卡了很久。后来自己写了个网页标注工具，全中文，选文件夹、拖框、导出，一步一步很直白。

导出的 JSON 记着每张图每个框的类别和位置。我又写了个脚本把它转成 YOLO 格式（每张图一个 txt，每行是「类别 中心x 中心y 宽 高」，数值归一化到 0~1），按 8:2 分成训练/验证，最后是 24 张训练、5 张验证。

## 四、模型训练

模型用 ultralytics 的 YOLO11n（nano 版）。参数：输入 640，batch 8，训练 60 轮，用 GPU。

几分钟跑完，验证集结果：

| 类别 | mAP50 |
|---|---|
| 全部 | 0.838 |
| 障碍物 | 0.843 |
| 可乐 | 0.995 |
| 足球 | 0.675 |

可乐最好，足球稍差，估计样本少、框得也不太一致。

用训练好的模型（best.pt）检测几张没见过的图，能框出目标、标出类别和置信度。

## 六、遇到的问题和解决

1. 装环境时下载链接 404、conda 报 SSL 错误 → 改用 venv 建环境。
2. 想用开源模型自动框图，它依赖的组件要从 GitHub 拉，网络不通，放弃，改成手动标。
3. 在线标注工具全英文看不懂 → 自己写了个中文工具。
4. 有一张障碍物图漏标了，影响不大，没补。
5. "障碍物"这个类边界模糊，我按图里主要的那个目标物体来框。
