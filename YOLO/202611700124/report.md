## 二、 目标检测标注 (Level 2)

### 2.1 标注工具与类别定义
为了更深刻理解 YOLO 标签格式，本项目编写了基于 OpenCV 的轻量级标注工具 `annotate.py`。类别编号定义如下：
- `0: obstacle` (障碍物)
- `1: cola` (可乐)
- `2: football` (足球)

### 2.2 标注过程与格式解析
在工具中鼠标拖拽绘制边界框，按下对应数字键进行分类，按 `s` 保存为 YOLO 格式的 `.txt` 文件。

*标签格式理解*：每一行代表一个目标，格式为 `<class_id> <x_center> <y_center> <width> <height>`。其中坐标均经过归一化处理（除以图片宽高），数值在 0~1 之间。

## 六、 遇到的问题与解决方案

1. **CUDA 设备报错**：初始配置 `device=0` 时提示 `Invalid CUDA 'device=0' requested`。原因本地无独立显卡。**解决**：修改 `train.py`，指定 `device="cpu"` 使用CPU训练。
2. **模型下载失败**：运行训练时提示 `SSLError`，无法从 GitHub 自动下载 `yolov8n.pt`。**解决**：手动在浏览器下载该权重文件，放入项目根目录，并在代码中改为 `YOLO("./yolov8n.pt")` 离线加载。
3. **数据集路径错误**：提示 `images not found`。**解决**：检查并修改 `data.yaml` 中的 `path`，使用绝对路径并将反斜杠 `\` 改为正斜杠 `/`。
4. **权重文件路径嵌套**：训练时 `project` 参数设置不当导致 `runs/detect/runs/detect` 套娃。**解决**：修改 `project` 为绝对路径，并复制 `best.pt` 到根目录供推理脚本和网页端使用。
